# Bond and collateral calculators

This is a static website. To host it with GitHub Pages, push the repository and select **Settings → Pages → Build and deployment → Deploy from a branch**, then choose the branch and **/(root)**. `index.html`, `js/`, the CSS, and the JSON data files must stay together at the repository root. No build step or server API is required.

The Collateral Monitor reads Normal and K250 share quantities from `funds.json` and its bond choices from `bonds.json`. Enter a purchase price, select a bond code, enter a stock code and percentages, then fetch the stock history. It calls the VPS daily history endpoint directly from the browser. A [complete NAB example request](https://histdatafeed.vps.com.vn/tradingview/history?symbol=NAB&resolution=1D&from=1790000000&to=1792454400&countback=30) returns JSON; the bare endpoint URL requires query parameters and returns HTTP 400. The endpoint currently permits cross-origin requests, so it works on GitHub Pages while that policy remains in place.

The [published GitHub Pages site](https://ngocdunga.github.io/bond_price_calculation/) will show the Collateral Monitor only after the changed files and `funds.json` are committed and pushed to the Pages branch.

The market endpoint provides daily closes and volumes, so the displayed price is the **volume weighted average of daily closing prices over the latest 20 valid sessions**. The 20 daily closes, volumes, and volume weights appear in a table below the calculator. VPS quotes are treated as thousands of VND per share. The secured obligation is `investment × 1.15²`; required collateral is `obligation × minimum CR / 100`, then split by the shares and bonds percentages. Required shares are `ceil(share allocation / weighted closing price)` and required bonds are `ceil(bond allocation / (par + accrued interest))`. Accrued interest uses the same coupon schedule, bank rates, settlement date, and recording period rule as the Price Calculator. Minimum CR defaults to 100%. The projected CR uses both rounded quantities and their calculated unit prices. Weekends are skipped when choosing the API date window; the API's returned sessions determine the actual 20 days, including exchange holidays.
